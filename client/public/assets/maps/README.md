# Peta

Aset peta yang dipakai renderer Canvas2D:

- `map_kampung.png` — tekstur tanah cadangan.
- `tileset_kampung.png` — cadangan tekstur ubin.
- `pos_ronda.png` — ikon gardu ronda generik.
- `design_map.png` — hasil crop sisi kiri `Deisgn Map dan tower.png`, dipakai sebagai seni peta arena dan latar minimap.
- `design_tower.png` — hasil crop sisi kanan (arsip desain; tidak dipakai di arena).
- `design_map_tower.png` — sheet lengkap (arsip desain; tidak dipakai di lobby).

Semua file dihasilkan oleh `npm run assets:process`.
